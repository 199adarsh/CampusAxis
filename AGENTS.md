# Project Instructions: CampusAxis / EduVault

## Icon Standard (MANDATORY)
- **Use Huge Icons (`hugeicons-react`) exclusively** for all UI icons across the entire project.
- **Do not introduce or use `lucide-react`, `heroicons`, or other icon sets.**
- When adding, editing, or refactoring UI components, always import icons from `hugeicons-react` (e.g. `Delete02Icon`, `Download01Icon`, `FullScreenIcon`, `Search01Icon`, `File01Icon`, etc.).
